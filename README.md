# Student Database Management System

A ServiceNow application developed to manage student information, admission details, academic records, attendance, and fee details.

## Modules

- Student
- Admission
- Academic
- Attendance
- Fee

## ServiceNow Configuration

### Custom Tables and Forms

Created custom tables and corresponding forms for managing:

- Student records
- Admission details
- Academic details
- Attendance records
- Fee details

### Business Rules

Used Business Rules to automate:

- Percentage calculation
- Grade calculation
- Attendance percentage calculation
- Fee outstanding calculation

### Client Scripts

Used Client Scripts for form validation and dynamic form behavior.

### UI Policies

Used UI Policies to control field behavior based on form conditions.

### Flow Designer

Configured a Flow Designer process for low-attendance notifications when a student's attendance falls below the defined threshold.

### UI Builder

Created application pages and dashboards to display student-related information.

## Technologies

- ServiceNow
- Business Rules
- Client Scripts
- UI Policies
- Flow Designer
- UI Builder
