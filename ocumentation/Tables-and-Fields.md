# Tables and Fields

The Student Database Management System uses custom tables to manage student-related information.

## Student Table

Stores the main student information.

## Admission Table

Stores admission details associated with students.

## Academic Table

Stores student academic information and is used for percentage and grade calculations.

## Attendance Table

Stores student attendance information and is used to calculate attendance percentage and check the attendance threshold.

## Fee Table

Stores student fee information and is used to calculate the outstanding fee amount.
